 Игра «Крестики-нолики» (Windows Forms)

Простое десктопное приложение для игры в крестики-нолики на поле 3х3. 

 Функционал
* Поочередные ходы для игроков **X** и **O**
* Автоматическая проверка победы и ничьей
* Кнопка быстрого перезапуска матча «начать заново»

 Стек
* C# / .NET
* Windows Forms

 Запуск
1. Открой файл решения `.sln` в **Visual Studio**.
2. Нажми `F5` для сборки и запуска.

 Интерфейс приложения
![Пример игры (Ничья)](./image_o0aJyZ.png)

   Нажмите клавишу `F5` или кнопку **«Пуск»** (Start) в панели инструментов Visual Studio, чтобы скомпилировать и запустить игру.

 Как играть
1. Игра начинается с первого хода игрока **X**.
2. Игроки поочередно нажимают на свободные серые квадратные кнопки на поле 3х3.
3. Побеждает тот, кто первым выстроит три своих знака в ряд (по вертикали, горизонтали или диагонали).
4. Если свободного места не осталось, а победитель не выявлен, приложение зафиксирует статус **«Ничья!»**.
5. Для новой партии нажмите кнопку **«начать заново»**.
